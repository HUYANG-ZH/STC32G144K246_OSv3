# 无线控制命令

本文档记录当前工程已经注册的无线控制命令。命令由无线串口接收，经 `service_packet_update()` 解析执行。

## 通讯配置

| 项目 | 当前配置 |
| --- | --- |
| 无线串口 | `UART_8` |
| 波特率 | `115200` |
| MCU RX / 模块 TX | `UART8_RX_P92` |
| MCU TX / 模块 RX | `UART8_TX_P93` |
| RTS 引脚 | `IO_P91` |
| 传输模式 | RTS 模式 |

## 帧格式

```text
$$命令,名称,数值@
```

当前解析器收到第一个 `@` 就结束并解析一帧；发送 `@@` 也可以，第二个 `@` 会被下一轮状态机忽略。

字段分隔符支持：

```text
,  :  =  空格  Tab
```

数值分隔符支持：

```text
,  ;  |  空格  Tab
```

当前已注册变量均为单个 `float` 数值，写入时只需要发送一个数值。

## 命令类型

| 命令 | 功能 | 示例 |
| --- | --- | --- |
| `R` | 读取变量 | `$$R,negative_pressure@` |
| `W` | 写入变量 | `$$W,negative_pressure,30@` |
| `T` | 触发动作 | `$$T,speed_stop@` |

读取成功或写入成功时，会通过无线串口回复：

```text
名称,数值\r\n
```

数值固定保留 3 位小数，例如：

```text
negative_pressure,30.000
```

动作命令没有统一成功回包；如果动作内部需要回复，会由动作自己通过 `wprint()` 输出。

## 已启用变量

这些变量支持 `R` 读取和 `W` 写入。

| 名称 | 功能 | 范围 / 单位 | 默认值 | 写入示例 |
| --- | --- | --- | --- | --- |
| `negative_pressure` | 负压控制百分比 | `0 ~ 100 %` | `0` | `$$W,negative_pressure,30@` |
| `speed_left_target` | 左轮目标速度 | `-10.0 ~ 10.0 m/s`，超限会钳位 | `0` | `$$W,speed_left_target,0.2@` |
| `speed_left_kp` | 左轮速度环 `Kp` | 浮点数 | `1500` | `$$W,speed_left_kp,1500@` |
| `speed_left_ki` | 左轮速度环 `Ki` | 浮点数 | `20000` | `$$W,speed_left_ki,20000@` |
| `speed_right_target` | 右轮目标速度 | `-10.0 ~ 10.0 m/s`，超限会钳位 | `0` | `$$W,speed_right_target,0.2@` |
| `speed_right_kp` | 右轮速度环 `Kp` | 浮点数 | `1500` | `$$W,speed_right_kp,1500@` |
| `speed_right_ki` | 右轮速度环 `Ki` | 浮点数 | `20000` | `$$W,speed_right_ki,20000@` |
| `motion_pre_linear_mps` | 巡线基础直线速度 | `m/s` | `0` | `$$W,motion_pre_linear_mps,0.2@` |
| `motion_pre_yaw_rate_gain` | 电感误差到目标角速度的增益 | `rad/s` | `1` | `$$W,motion_pre_yaw_rate_gain,1.0@` |
| `feedforward_kff` | 前馈增益 | 浮点数 | `0` | `$$W,feedforward_kff,1.0@` |
| `motion_post_kp` | 角速度闭环 PID `Kp` | 浮点数 | `0` | `$$W,motion_post_kp,1.0@` |
| `motion_post_ki` | 角速度闭环 PID `Ki` | 浮点数 | `0` | `$$W,motion_post_ki,0.1@` |
| `motion_post_kd` | 角速度闭环 PID `Kd` | 浮点数 | `0` | `$$W,motion_post_kd,0.5@` |
| `motion_post_integral_limit` | 角速度闭环积分限幅 | `0` 表示不限制 | `0` | `$$W,motion_post_integral_limit,5.0@` |
| `motion_post_output_limit` | 角速度闭环输出限幅 | 差速目标限幅 | `10` | `$$W,motion_post_output_limit,10.0@` |
| `motion_post_enable` | 运动后处理使能 | `>=0.5` 开启，`<0.5` 关闭转向闭环并清 PID | `1` | `$$W,motion_post_enable,1@` |

读取示例：

```text
$$R,negative_pressure@
$$R,speed_left_target@
$$R,speed_right_target@
$$R,motion_pre_linear_mps@
$$R,motion_pre_yaw_rate_gain@
$$R,feedforward_kff@
$$R,motion_post_kp@
$$R,motion_post_ki@
$$R,motion_post_kd@
$$R,motion_post_integral_limit@
$$R,motion_post_output_limit@
$$R,motion_post_enable@
```

## 已启用动作

这些动作使用 `T` 命令触发。

| 名称 | 功能 | 回复 | 示例 |
| --- | --- | --- | --- |
| `speed_stop` | 清零左右轮目标速度、清零输出 PWM、复位速度 PID，并调用电机停止 | 无固定回复 | `$$T,speed_stop@` |
| `battery_voltage` | 立即采样电池电压并通过无线返回 | `battery_voltage,电压值` | `$$T,battery_voltage@` |

## 常用控制示例

查询电池电压：

```text
$$T,battery_voltage@
```

设置负压为 30%：

```text
$$W,negative_pressure,30@
```

设置左右轮目标速度为 `0.2 m/s`：

```text
$$W,speed_left_target,0.2@
$$W,speed_right_target,0.2@
```

直接停止速度输出：

```text
$$T,speed_stop@
```

设置巡线基础控制量：

```text
$$W,motion_pre_linear_mps,0.2@
$$W,motion_pre_yaw_rate_gain,1.0@
```

设置角速度闭环 PID 参数：

```text
$$W,motion_post_kp,1.0@
$$W,motion_post_ki,0.1@
$$W,motion_post_kd,0.5@
```

关闭运动后处理转向闭环：

```text
$$W,motion_post_enable,0@
```

## 注意事项

- 上电后 `motion_pre_linear_mps` 默认是 `0`，车辆不会主动前进；需要写入基础速度后才会运动。
- `motion_pre_yaw_rate_gain` 默认是 `1`，电感误差会生成目标角速度；但 `motion_post_kp/ki/kd` 默认都是 `0`，不写入 PID 参数时不会形成有效差速修正。
- `motion_post_enable` 只控制运动后处理转向闭环。设为 `<0.5` 后会清 PID，但不会把 `motion_pre_linear_mps` 或速度环目标当作停车开关清零。
- `speed_stop` 会停止速度环输出，但当前命令表没有重新使能速度环的动作；触发后需要复位或补充使能接口才能恢复闭环输出。
- `W` 命令写入成功后会回读该变量当前值；负压和目标速度存在钳位逻辑，最终执行值以模块任务更新后的实际状态为准。
