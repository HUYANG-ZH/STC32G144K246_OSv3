# 无线控制命令

本文档记录当前工程已经启用的无线控制命令。命令由无线串口接收，经 `service_packet_update()` 解析执行。

## 通讯配置

| 项目 | 当前配置 |
| --- | --- |
| 无线串口 | `UART_8` |
| 波特率 | `115200` |
| MCU RX / 模块 TX | `UART8_RX_P92` |
| MCU TX / 模块 RX | `UART8_TX_P93` |
| RTS 引脚 | `IO_P91` |
| 传输模式 | RTS 模式 |

## 帧格式

```text
$$命令,名称,数值@
```

当前代码实际在收到第一个 `@` 时结束并解析一帧；发送 `@@` 时也会在第一个 `@` 触发解析，第二个 `@` 会被忽略。

字段分隔符支持：

```text
,  :  =  空格  Tab
```

数值分隔符支持：

```text
,  ;  |  空格  Tab
```

目前已注册的变量都是单个 `float` 数值，因此写入时只需要发送一个数值。

## 命令类型

| 命令 | 功能 | 示例 |
| --- | --- | --- |
| `R` | 读取变量 | `$$R,negative_pressure@` |
| `W` | 写入变量 | `$$W,negative_pressure,30@` |
| `T` | 触发动作 | `$$T,speed_stop@` |

读取成功或写入成功时，会通过无线串口回复：

```text
名称,数值\r\n
```

数值固定保留 3 位小数，例如：

```text
negative_pressure,30.000
```

变量名不存在、写入数值解析失败、动作名不存在时，当前代码不会发送错误回复。

## 已启用变量

这些变量支持 `R` 读取和 `W` 写入。

| 名称 | 功能 | 范围 / 单位 | 写入示例 |
| --- | --- | --- | --- |
| `negative_pressure` | 负压控制百分比 | `0 ~ 100`，超限会钳位 | `$$W,negative_pressure,30@` |
| `speed_left_target` | 左轮目标速度 | `-10.0 ~ 10.0 m/s`，超限会钳位 | `$$W,speed_left_target,1.2@` |
| `speed_left_kp` | 左轮速度环 `Kp` | 浮点数 | `$$W,speed_left_kp,120@` |
| `speed_left_ki` | 左轮速度环 `Ki` | 浮点数 | `$$W,speed_left_ki,5@` |
| `speed_right_target` | 右轮目标速度 | `-10.0 ~ 10.0 m/s`，超限会钳位 | `$$W,speed_right_target,1.2@` |
| `speed_right_kp` | 右轮速度环 `Kp` | 浮点数 | `$$W,speed_right_kp,120@` |
| `speed_right_ki` | 右轮速度环 `Ki` | 浮点数 | `$$W,speed_right_ki,5@` |
| `motion_pre_linear_mps` | 运动前处理直线速度 | `m/s` | `$$W,motion_pre_linear_mps,1.0@` |
| `motion_pre_yaw_rate_gain` | 运动前处理角速度增益 | `rad/s`，乘以巡线误差得到目标角速度 | `$$W,motion_pre_yaw_rate_gain,2.0@` |
| `feedforward_kff` | 前馈增益 | 浮点数，乘以曲率得到前馈输出 | `$$W,feedforward_kff,1.0@` |
| `load_dist_enable` | 载荷分配使能 | `0/1`，当前只影响载荷分配框架输出 | `$$W,load_dist_enable,1@` |
| `load_dist_limit` | 载荷分配输出限幅 | 浮点数，补偿输出绝对值上限 | `$$W,load_dist_limit,1.0@` |

读取示例：

```text
$$R,negative_pressure@
$$R,speed_left_target@
$$R,speed_right_target@
$$R,motion_pre_linear_mps@
$$R,motion_pre_yaw_rate_gain@
$$R,feedforward_kff@
$$R,load_dist_enable@
$$R,load_dist_limit@
```

## 已启用动作

这些动作使用 `T` 命令触发。

| 名称 | 功能 | 示例 |
| --- | --- | --- |
| `speed_stop` | 清零左右轮目标速度、清零输出 PWM、复位速度 PID，并调用电机停止 | `$$T,speed_stop@` |

## 常用控制示例

设置负压为 30%：

```text
$$W,negative_pressure,30@
```

设置左右轮目标速度为 `1.2 m/s`：

```text
$$W,speed_left_target,1.2@
$$W,speed_right_target,1.2@
```

设置速度环参数：

```text
$$W,speed_left_kp,120@
$$W,speed_left_ki,5@
$$W,speed_right_kp,120@
$$W,speed_right_ki,5@
```

停止速度输出：

```text
$$T,speed_stop@
```

设置运动前处理基础控制量：

```text
$$W,motion_pre_linear_mps,1.0@
$$W,motion_pre_yaw_rate_gain,2.0@
```

## 注意事项

- 当前只注册了 `speed_stop` 动作，没有注册 `speed_start` 或速度使能变量。
- 上电初始化后速度输出默认处于使能状态；如果触发过 `speed_stop`，当前无线命令表里没有对应的重新使能命令。
- 速度环默认 `Kp`、`Ki` 为 `0`，需要写入合适的参数后，目标速度才会形成有效闭环输出。
- `W` 命令写入成功后会回读该变量当前值；负压和目标速度存在钳位逻辑，最终执行值以模块任务更新后的实际状态为准。
