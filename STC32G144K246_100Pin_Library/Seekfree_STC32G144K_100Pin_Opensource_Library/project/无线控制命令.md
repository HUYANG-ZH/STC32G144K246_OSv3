# 无线控制命令

本文档记录当前工程已经注册的无线控制命令。命令由无线串口接收，经 `service_packet_update()` 解析执行。

## 通讯配置

| 项目 | 当前配置 |
| --- | --- |
| 无线串口 | `UART_8` |
| 波特率 | `921600` |
| MCU RX / 模块 TX | `UART8_RX_P92` |
| MCU TX / 模块 RX | `UART8_TX_P93` |
| RTS 引脚 | `IO_P91` |
| 传输模式 | 4 线模式（`WIRELESS_UART_TRANSFER_MODE_4WIRE`） |

当前为 4 线全双工模式，`IO_P91` 的 RTS 流控未启用（仅 RTS 模式下使用）；自动波特率关闭。

## 帧格式

```text
$$命令,名称,数值@
```

当前解析器收到第一个 `@` 就结束并解析一帧；发送 `@@` 也可以，第二个 `@` 会被下一轮状态机忽略。

字段分隔符支持：

```text
,  :  =  空格  Tab
```

数值分隔符支持：

```text
,  ;  |  空格  Tab
```

当前已注册变量均为单个 `float` 数值，写入时只需要发送一个数值。

注意：`SLT` / `SRT`（左右轮目标速度）写入时校验 `|值| <= 10.0 m/s`，超限的写入会被**拒绝**（不生效、不回调、不回读），并非自动钳位。

## 命令类型

| 命令 | 功能 | 示例 |
| --- | --- | --- |
| `R` | 读取变量 | `$$R,negative_pressure@` |
| `W` | 写入变量 | `$$W,negative_pressure,30@` |
| `T` | 触发动作 | `$$T,stop@` |

读取成功或写入成功时，会通过无线串口回复：

```text
名称,数值\r\n
```

数值固定保留 3 位小数（四舍五入），例如：

```text
negative_pressure,30.000
```

动作命令没有统一成功回包；如果动作内部需要回复，会由动作自己通过 `wprint()` 输出。

## 已启用变量

这些变量支持 `R` 读取和 `W` 写入。

| 名称 | 功能 | 范围 / 单位 | 默认值 | 写入示例 |
| --- | --- | --- | --- | --- |
| `negative_pressure` | 负压**基础量**百分比；实际生效量由速度规划计算（基础量 + 触发增量，见 `pressure_boost`） | `0 ~ 100 %` | `0` | `$$W,negative_pressure,30@` |

| `SRK` | 右轮速度环 `Kp` | 浮点数 | `1570` | `$$W,SRK,1570@` |

| `motion_post_output_limit` | 角速度闭环输出限幅 | 差速目标限幅 | `5.0` | `$$W,motion_post_output_limit,5.0@` |

## 已启用动作

这些动作使用 `T` 命令触发。

| 名称 | 功能 | 回复 | 示例 |
| --- | --- | --- | --- |
| `stop` | 急停锁定（由开机流程模块注册并接管）：停止两轮速度输出链路、复位速度 PID、PWM 归零，并将负压设为 `0%`；若开机流程尚未完成，会中止开机并额外输出 `boot_abort,1.000` | `stop,0.000` | `$$T,stop@` |
| `start` | 解除急停（由开机流程模块注册并接管）：清除急停标志、重新使能两轮速度输出链路、蜂鸣 200 ms | `start_drive,1.000` | `$$T,start@` |
| `battery_voltage` | 立即采样电池电压并通过无线返回 | `battery_voltage,电压值` 或 `battery_voltage,pending` | `$$T,battery_voltage@` |

## 元素识别命令（条件注册）

`main.c` 中 `app_element_init()`（及主循环 `app_element_pump_events()`）当前被注释，**元素识别处于关闭状态**，因此以下变量与动作**当前不会注册**（发送对应命令会命中"未找到"，无回包）。

启用方法：在 `main.c` 中取消 `// app_element_init();` 的注释（同时取消主循环 `// app_element_pump_events();`），重新编译烧录后，元素识别（圆筒 / 跷跷板 / 环岛）与下列命令才会生效。

## 常用控制示例

查询电池电压：

```text
$$T,battery_voltage@
```

急停并关闭负压：

```text
$$T,stop@
```

急停后恢复两轮速度输出链路：

```text
$$T,start@
```

设置负压基础量为 30%（实际生效量由速度规划叠加）：

```text
$$W,negative_pressure,30@
```

设置左右轮目标速度为 `0.2 m/s`：

```text
$$W,SLT,0.2@
$$W,SRT,0.2@
```

设置巡线基础控制量：

```text
$$W,motion_pre_linear_mps,0.2@
$$W,motion_pre_yaw_rate_gain,0.62@
```

设置角速度闭环 PID 参数：

```text
$$W,motion_post_kp,1.0@
$$W,motion_post_ki,0.1@
$$W,motion_post_kd,0.5@
```

关闭运动后处理转向闭环：

```text
$$W,motion_post_enable,0@
```

## 注意事项

- 上电后 `motion_pre_linear_mps` 默认是 `0`，车辆不会主动前进；需要写入基础速度后才会运动。
- `motion_pre_yaw_rate_gain` 默认是 `0.62`，电感误差会生成目标角速度；但 `motion_post_kp/ki/kd` 默认都是 `0`，不写入 PID 参数时不会形成有效差速修正。
- 速度环参数默认值：左右 `Kp = 1570`、`Ki = 40000`；`SLT`/`SRT` 写入超出 ±10 m/s 会被拒绝（解析失败），不会钳位生效。
- `motion_post_enable` 只控制运动后处理转向闭环。设为 `<0.5` 后会清 PID，但不会把 `motion_pre_linear_mps` 或速度环目标当作停车开关清零。
- `stop` 是急停锁定动作（由开机流程模块注册），会停止速度输出链路并将负压设为 `0%`；开机流程未完成时触发会中止开机（输出 `boot_abort,1.000`）。
- `start` 由开机流程模块注册，回复为 `start_drive,1.000`；只恢复两轮速度输出链路，不自动恢复负压；如果 `motion_pre_linear_mps` 等上游目标仍为非零，运动后处理会继续下发目标速度。
- `negative_pressure` 现在语义为**基础量**，实际生效量由速度规划模块计算：当 `|pitch| > 30°`（或 TOF 接近 `<200 mm`）时，生效量 = 基础量 + `pressure_boost`（默认 `15`），上限 `90%`；触发结束后恢复基础量。触发期间写入 `negative_pressure` 会清除速度规划接管，按新基础量恢复控制。
- 负压 PWM 映射：`0%` 对应 5% 占空比，`100%` 对应 10% 占空比，线性映射；写入值自动钳位到 `0 ~ 100`。
- `W` 命令写入成功后会回读该变量当前值；只有值发生变化时才会触发该变量的写入回调（如速度环 PID 重启、目标速度发布）。
- IMU 陀螺仪校准仅提供代码接口（`service_imu_start_calibration()` 等），**当前未注册任何校准相关的无线命令**。
- 元素识别相关命令（`cylinder_*`、`seesaw_event`、`roundabout_count`、`round_*` 等）为条件注册：当前 `main.c` 中 `app_element_init()` 被注释，元素识别关闭，这些命令不可用；取消注释并重新编译后才生效。
