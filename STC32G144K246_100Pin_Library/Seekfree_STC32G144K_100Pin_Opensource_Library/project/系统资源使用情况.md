# 系统资源使用情况

> 本文件依据工程代码逐项核查（2026-08-07），与 `out_file/SEEKFREE.map` 构建产物一致。
> 元素识别当前在 main.c 中被注释关闭（`app_element_init` / `app_element_pump_events` / `app_element_control_step` / `app_element_imu_task` 均未启用）。

## 定时器资源

| 资源 | 使用 | 中断优先级 | 用途 |
| --- | --- | --- | --- |
| `TIM0` | 是 | 默认 | `service_timetick` PIT，100us 系统时间戳（`service_timetick.c`） |
| `TIM1` | 是 | - | Debug UART1 波特率发生器（`uart_init(UART_1)` 默认映射 TIM_1，1Mbps） |
| `TIM2` | 是 | 默认 | `app_scheduler` PIT，1ms 调度心跳（只更新任务就绪标志，不执行任务函数） |
| `TIM3` | 是 | 3 | `service_speed` PIT，1ms 编码器速度采样与 LPF（`service_speed.c:39`） |
| `TIM4` | 是 | 3 | `app_inductor_preprocess` PIT，1ms（`pit_us_init` 1000us）电感采样与归一化预处理（`app_inductor_preprocess.c:318`） |
| `TIM5` | 是 | 3 | `app_speedout` PIT，1ms 速度输出环：左右轮速度 PID + 电机 PWM + 负压 PWM 执行（`app_speedout.c:218`，`service_negative_pressure_apply_request` 在此调用） |
| `TIM6` | 是 | 3 | **单一 5ms 控制链**：`app_motion_postprocess_control_step` 依次调用 motion_preprocess →（element 已注释关闭）→ feedforward → speed_plan → postprocess 角速度环（`app_motion_postprocess.c:279`） |
| `TIM7` | 是 | 3 | `app_motion_postprocess` IMU 任务，1ms：`service_imu_update` 快照、gz LPF、`app_attitude_update` 姿态更新、IMU 新鲜度看门狗；`app_element_imu_task` 已注释关闭（`app_motion_postprocess.c:283`） |
| `TIM8` | 是 | 3（UART8 DMA） | Wireless UART8 波特率发生器（921600）——**仅供 UART8 使用，不可再作 PIT** |
| `TIM9` | 是 | 3 | `app_battery_guard` PIT，10ms 电池低压/采样超时互锁（`app_battery_guard.c`，阈值 10.6V 滤波后电压，联锁永久锁存，触发时主循环输出有线+无线报警） |
| `TIM10/11/17/18` | 否 | - | 空闲 |

## 通信资源

| 资源 | 使用 | 用途 |
| --- | --- | --- |
| `UART_1` | 是 | Debug UART，`DEBUG_UART_BAUDRATE=1000000`（1Mbps），`UART1_TX_P31` / `UART1_RX_P30`；RX DMA 回调 `uart_rx_handlers[UART_1]` 被 `service_boot_request_feed_byte` 占用（`service_boot_request_init`），用于上位机 FastBoot 跳转命令解析（帧前缀 `SBLR`，ACK 10 字节回发） |
| `UART_8` | 是 | 无线串口，`WIRELESS_UART_BAUD_RATE=921600`，4 线模式（`WIRELESS_UART_TRANSFER_MODE_4WIRE`，`AUTO_BAUD_RATE=0`），`UART8_RX_P92`（模块 TX） / `UART8_TX_P93`（模块 RX），DMA 中断优先级 3 |
| `IO_P91` | 否 | 无线串口 RTS（头文件定义）——**4 线模式下未初始化、未使用**（仅在 RTS 模式/自动波特率模式才会 `gpio_init`） |
| `SPI_3` | 是 | IMU660RC（`bsp_imu`，`zf_device_imu660rc.h`），10MHz 硬件 SPI、Mode0，`spi_dma_init` 单次 DMA 异步读取完整 FIFO 帧 |
| `SPI3_CH3_SCLK_P87` | 是 | IMU660RC SCK |
| `SPI3_CH3_MOSI_P85` | 是 | IMU660RC MOSI |
| `SPI3_CH3_MISO_P86` | 是 | IMU660RC MISO |
| `IO_P84` | 是 | IMU660RC CS（bsp_imu 用 `P8SETB/P8CLRB` 原子操作，避免与 P8 口电机方向脚读写竞争） |
| `GPIO_INIT_P37` | 是 | IMU660RC INT2：FIFO 水位中断（上升沿，优先级 2）。**当前 `BSP_IMU_QUARTERNION_RATE=IMU660RC_QUARTERNION_DISABLE`，FIFO 帧为 gyro + acc 两字（无 SFLP 四元数），roll/pitch 由加速度计解算**；中断仅锁存事件，SPI3 单次 DMA 读取完整帧 |
| `IIC_1` | 否 | TOF 测距：`BSP_TOF_DRIVER=DL1A`（`bsp_tof.h`），硬件 IIC `IIC_1`，`IIC1_CH3_SCL_P77` / `IIC1_CH3_SDA_P76`，400kHz，INT/XS 未启用（`zf_device_dl1a.h`）。**当前 `SERVICE_TOF_ENABLE=0`（`service_tof.h`），不初始化不采样，IIC_1 未占用** |

## ADC 资源

| 资源 | 使用 | 用途 |
| --- | --- | --- |
| `ADC1_CH0_P10` | 是 | 电池电压采样（`bsp_battery.c`，量程系数 36.4737V），ADC1 DMA 8 次采样+硬件平均值，`service_batterycheck` 每 100ms 触发一次并低通（α=0.1）后发布；`app_battery_guard`（TIM9 低压互锁，10ms）消费滤波后电压 |
| `ADC2_CH3_P03` | 是 | 电感通道 1 |
| `ADC2_CH4_P04` | 是 | 电感通道 2 |
| `ADC2_CH5_P05` | 是 | **中间电感 M**（旧文档缺失，已补） |
| `ADC2_CH6_P06` | 是 | 电感通道 4 |
| `ADC2_CH7_P07` | 是 | 电感通道 3 |

说明：5 路电感由 ADC2 DMA 一次扫描完成（`DMA_ADC2_CHSW0=0xF8` = CH3..CH7，每通道 8 次转换+硬件平均值，完成中断优先级 2），DMA 缓冲顺序按通道号 CH3→CH7 排列（`bsp_inductor.c`）。

## 调度器资源

- `app_scheduler`：TIM2 1ms 心跳（`app_scheduler.c:40`），任务表容量 `APP_SCHEDULER_TASK_MAX=10`，主循环 `app_scheduler_run` 每次最多执行一个就绪任务（同优先级按 id 小者优先）。
- 当前注册任务（`app_scheduler_add` 全局唯一调用点，`app_boot_sequence.c:122`）：

| 任务 id | 任务函数 | 优先级 | 周期 | 用途 |
| --- | --- | --- | --- | --- |
| 5 | `app_boot_task` | 1 | 10ms | 开机时序：beep(500ms) → wait(2s) → 负压 60%(2s) → 自动启动，可被无线 `stop`/`start` 命令中止/接管 |

- 主循环其余任务：`iic_async_process_all_timed`、`service_imu_task`、`service_tof_task`、`service_batterycheck_task`、`service_inductor_task`、`service_boot_request_process`、`service_function_queue_update`、`service_packet_update`、`app_scheduler_run`、`service_negative_pressure_task`、`service_buzzer_task`、`service_led_task`、`service_button_task`（`main.c`）。
- 控制闭环不经过调度器：TIM3/4/5/6/7 直接承载速度采样、电感预处理、速度环与 5ms 控制链（优先级 3，可抢占主循环）。
