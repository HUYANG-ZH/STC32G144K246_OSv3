# 系统资源使用情况

## 定时器资源

| 资源 | 使用 | 用途 |
| --- | --- | --- |
| `TIM0` | 是 | `service_timetick` PIT，100us 时间戳 |
| `TIM1` | 是 | Debug UART1 波特率发生器 |
| `TIM2` | 是 | `app_scheduler` PIT，1ms 调度心跳 |
| `TIM3` | 是 | `service_speed` PIT，1ms 速度采样 |
| `TIM4` | 是 | `app_inductor_preprocess` PIT，1ms 电感采样与预处理 |
| `TIM5` | 是 | `app_speedout` PIT，1ms 速度输出环 |
| `TIM6` | 是 | `app_motion_preprocess` PIT，5ms 运动前处理 |
| `TIM7` | 是 | `app_element` PIT，5ms 元素识别 |
| `TIM8` | 是 | Wireless UART8 波特率发生器 |
| `TIM9` | 是 | `app_motion_postprocess` PIT，3ms gz 采样与角速度环 |

## 通信资源

| 资源 | 使用 | 用途 |
| --- | --- | --- |
| `UART_1` | 是 | Debug UART，`UART1_TX_P31` / `UART1_RX_P30` |
| `UART_8` | 是 | 无线串口，`UART8_RX_P92` / `UART8_TX_P93` |
| `IO_P91` | 是 | 无线串口 RTS 输入 |
| `SPI_3` | 是 | IMU660RC，10MHz 硬件 SPI |
| `SPI3_CH3_SCLK_P87` | 是 | IMU660RC SCK |
| `SPI3_CH3_MOSI_P85` | 是 | IMU660RC MOSI |
| `SPI3_CH3_MISO_P86` | 是 | IMU660RC MISO |
| `IO_P84` | 是 | IMU660RC CS |
| `GPIO_INIT_P37` | 否 | IMU660RC INT2，当前关闭自解算和 INT 中断，未占用 |

## ADC 资源

| 资源 | 使用 | 用途 |
| --- | --- | --- |
| `ADC1_CH0_P10` | 是 | 电池电压采样 |
| `ADC2_CH3_P03` | 是 | 电感通道 1 |
| `ADC2_CH4_P04` | 是 | 电感通道 2 |
| `ADC2_CH6_P06` | 是 | 电感通道 3 |
| `ADC2_CH7_P07` | 是 | 电感通道 4 |

## PWM 与编码器资源

| 资源 | 使用 | 用途 |
| --- | --- | --- |
| `PWMC` | 是 | 左右电机 PWM，10kHz |
| `PWMC_CH1P_P80` | 是 | 左电机 PWM |
| `PWMC_CH2P_P82` | 是 | 右电机 PWM |
| `PWMD_CH1_PB4` | 是 | 负压控制 PWM，50Hz |
| `PWME_ENCODER` | 是 | 左编码器 |
| `PWME_ENCODER_CH1P_PA0` | 是 | 左编码器脉冲 |
| `PWME_ENCODER_CH2P_PA2` | 是 | 左编码器方向 |
| `PWMF_ENCODER` | 是 | 右编码器 |
| `PWMF_ENCODER_CH1_PA1` | 是 | 右编码器脉冲 |
| `PWMF_ENCODER_CH2_PA3` | 是 | 右编码器方向 |

## GPIO 资源

| 资源 | 使用 | 用途 |
| --- | --- | --- |
| `IO_P22` | 是 | 蜂鸣器，高电平有效 |
| `IO_P61` | 是 | 左右电机驱动 NSLEEP/RESET |
| `IO_P62` | 是 | 左电机方向 |
| `IO_P83` | 是 | 右电机方向 |
